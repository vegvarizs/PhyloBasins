# BalkanFishes Validation

This directory contains the complete validation workflow used to
reproduce the historical BalkanFishes analyses with PhyloBasins.

Workflow:

1. Create project
2. Compute metrics
3. Compare against historical results
4. Create validation maps
5. Generate validation report
6. Run the complete workflow

Expected outcome:

- Numerical reproduction: PASS
- Map reproduction: PASS
- Validation report: PASS
